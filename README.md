# Scheurkalender 2027 – feedbackronde

Swipe-pagina waarmee collega's van Transformatie Palliatieve Zorg Midden-Nederland de dagen van de conceptscheurkalender 2027 beoordelen.

**Openen:** https://anneloesb.github.io/scheurkalender-2027/

## Zo werkt het
1. Kies je naam en welke kaarten je wilt zien: je eigen blok, alle kaarten, alleen gewijzigde kaarten, alleen spreuken of de kaarten van Leven tot het laatst.
2. Filter eventueel op een kernelement: signaleren & markeren, proactieve zorgplanning, casemanagement & continuïteit, of consultatie bij complexe problematiek.
3. Swipe naar rechts (👍) of links (👎). Bij 👎 kun je feedback geven.
4. Druk op **Ik ben klaar**, kopieer de tabel en mail die naar Anneloes.

Je voortgang wordt bewaard in je eigen browser; er wordt niets naar een server gestuurd.
